# shiba-train-log
筋トレ管理アプリ

## 利用環境とデータの保存

- iPhoneのSafariではHTTPSのURLで利用してください（例：GitHub Pages）。
- 記録はこのブラウザのlocalStorageに保存されます。端末間の自動同期はありません。JSON書き出しで定期的にバックアップしてください。
- 保存に失敗した場合、新規登録・削除・JSON復元・全件削除・サンプル追加を反映せず、変更前のデータを維持します。
- JSON復元では既存の有効な文字列IDを維持します。IDなし・不正なID・重複ID（2件目以降）は暗号学的な乱数で再発行し、各記録を残します。UUID形式以外の既存ID（`demo-1`など）も利用できます。
- `crypto.randomUUID()`がない環境では`crypto.getRandomValues()`でUUIDを作成します。既存IDとの重複を確認し、安全な乱数が使えない場合は登録を中止します。
- 実在しない日付のJSONは復元を拒否します。保存先のキーと既存の記録形式は変更していません。

## テスト

Node.js 18以降で、外部ライブラリのインストールなしに実行できます。

```sh
node tests/data-safety.test.cjs
```

日付・うるう年、ID生成と衝突回避、ID補完、既存データの再読み込み、保存失敗時のデータ保持を検証します。

ブラウザでの確認手順：

1. `python3 -m http.server 8000`を起動し、PCで`http://localhost:8000`を開きます。
2. 記録を保存し、再読み込み後の履歴と集計を確認します。
3. JSONを書き出してから削除し、JSON読み込みで復元します。
4. テスト用JSONのIDを削除・重複させ、復元後も全件残り、1件ずつ削除できることを確認します。
5. 日付を`2026-02-31`にしたJSONが拒否され、既存記録が残ることを確認します。

AIサーバーやApple Watchの自動連携はこの修正に含まれません。
